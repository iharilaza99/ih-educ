# Bibliothèque numérique

Accédez à vos supports de cours, livres et exercices corrigés.

## Ressources disponibles
Les fichiers de la bibliothèque doivent être ajoutés dans `docs/assets/`. Exemple de structure :

- `docs/assets/cours_informatique_intro_reseaux.pdf`
- `docs/assets/developpement_web_architecture_php.pdf`
- `docs/assets/latex_modeles_examens.pdf`

Exemples de liens de téléchargement à utiliser dans cette page :

- **Cours Informatique :** Introduction aux réseaux et serveurs — [Télécharger](assets/cours_informatique_intro_reseaux.pdf)
- **Développement Web :** Architecture PHP et bases de données — [Télécharger](assets/developpement_web_architecture_php.pdf)
- **LaTeX :** Modèles de feuilles d'examens — [Télécharger](assets/latex_modeles_examens.pdf)

(Remplacez les noms de fichiers par les documents réels présents dans `docs/assets/`.)
